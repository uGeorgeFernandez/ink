Install

Up and running in four steps

INK builds from source. On Windows, do all of this inside WSL (a free Linux terminal for Windows).

Install the tools

INK needs the NASM assembler and LLVM/Clang. On Ubuntu or Debian:

sudo apt-get install nasm llvm clang

Get INK

Clone the repository (or download and unzip the .zip above):

git clone https://github.com/uGeorgeFernandez/ink
cd ink

Build the compiler

One command assembles and links INK:

./build.sh

Write & run

Save first.in, then run it:

show "Hello from INK!"
./ink.sh first.in

What's inside the download

  • The INK compiler — lexer, parser and code generator (x86-64 Assembly)
  • build.sh to build it, ink.sh to run your programs
  • 8 example programs and a folder of test programs
  • The Language Guide, Words Reference and Phases docs
  • The full source, MIT-licensed — read it, change it, share it

Requirements

  • Linux on x86-64 — the only platform INK runs on today.
  • Windows: install WSL and work inside it.
  • macOS / Apple Silicon: not supported yet — use a Linux VM or WSL on a PC.
  • Tools: nasm and clang (installed in step 1).
Release notes

What works in v0.8

INK is an honest working prototype. Here is exactly what it can and cannot do today.

Working
  • Variables, constants, numbers (num) and text
  • Decisions (if / else if / else) and loops (for, while, loop)
  • Functions, return values and recursion
  • Lists and maps, with built-ins (len, sum, min, max, abs)
  • Keyboard input and reading / writing files
  • Type checking and memory-safe list access

Known limitations

  • No modules / import yet — one program, one file.
  • Memory isn't freed yet, so very long-running programs grow.
  • read_file reads up to 64 KB.
  • Error messages don't show line numbers yet.
